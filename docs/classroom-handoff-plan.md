# 课堂交接与五分钟演示方案

日期：2026-10-30。状态：方案已整理，尚未执行交接。适用当前小芽口算工程。

## 目标与路线

让负责展示的同学使用自己的电脑，独立完成约五分钟的真实操作演示，不依赖开发者电脑或教室互联网。沿用现有Vue前端、Java后端、MySQL数据库，不重写架构。S02学生完整学情仍取消；本次不扩大教学覆盖、答案类型或家长历史范围。

采用“展示电脑本地完整部署”：浏览器 → 本机网页服务 → 本机Java后端 → 本机MySQL。前端构建后在本机提供访问，不依赖开发服务器或云端静态网站。具体服务入口实现待交接准备时核对确定，不在本轮新增脚本。

比较过的方式：连接开发者电脑会依赖其开机及现场网络；云端前端连接本机后端会增加证书、跨域和浏览器访问配置。因此独立本地部署作为课堂主方案；多人局域网试用作为后续可选工作，不作为五分钟展示的前置条件。暂不购买服务器、不配置公网通道。

## 执行顺序

1. **先完成项目小优化。**用户给出问题或优化清单后，逐项确认涉及页面、预期行为和验收点，再修改及执行对应检查。当前尚无具体清单，不自行加功能或修改已确定范围。
2. **形成课堂候选版本。**优化验证通过后，记录实际源码状态及工作区指纹；如生成新APK/JAR/Web包，使用独立批次目录和文件名，不覆盖冻结I2/I3/S01产物。只补跑与改动相关的测试和核心演示流程，历史51/29/5不冒报为新版本结果。
3. **再准备源码上传和交接。**先检查拟上传内容和目标Gitee仓库、分支、可见性及权限，明确本批操作授权后再提交上传。已有个人私有GitHub上传是历史事实，本方案不立即更新它，也不自动新增远端或推送。
4. **准备展示电脑。**核对操作系统、CPU架构、可用空间、已有Java/MySQL及端口，再提供匹配的部署说明和独立演示数据。提前安装依赖并完成一次联网准备；课堂运行应不依赖下载工具或访问远程资源。不能把开发电脑的临时工具路径直接复制为通用说明。
5. **在展示电脑验收并彩排。**实际启动、断网检查、完成演示主线，记录成功及未测项。需要录屏备份时再制作，不把已有截图或方案视为已完成的现场验证。

## 交接内容与边界

源码仓库拟包含：前后端源码、测试、部署脚本与说明、数据库结构初始化方法及审查后的脱敏演示数据。结构初始化沿用现有Flyway V1–V7机制，不另造一套冲突建表流程。

另行交付运行材料：同版前端构建产物、后端JAR、必要时的APK、校验清单和运行环境准备说明。是否附带可分发工具、采用何种压缩包，在目标电脑条件确定后选择，不承诺无需环境准备的通用便携包。

不得直接上传现有`.local`、私有runtime配置、证书私钥、数据库备份、密码、令牌、日志或真实个人数据。展示账号由独立配置或初始化步骤建立，密码不进入源码。演示数据从已审查的最小样例生成，不直接复制整个开发库/测试库备份。目标电脑使用独立数据库或实例，不能覆盖已有业务数据。

接收电脑上的练习和成绩独立保存，不自动同步开发电脑。若多名同学需要共享试用数据，再选择共同连接同一服务；此项另行安排。

## 五分钟演示建议

| 时间 | 操作 |
|---|---|
| 0:00–0:30 | 简述学生、家长、管理员角色及APP/Web共享服务 |
| 0:30–2:00 | 学生配置多知识点练习，保存后继续，提交并查看成绩解析 |
| 2:00–3:30 | 家长为已关联孩子预览并发送固定题目；学生接收并完成 |
| 3:30–4:30 | 家长查看结果和学情；学生查看错题及原题重练 |
| 4:30–5:00 | 总结已实现范围，管理员入口或APP作为时间允许时的补充 |

以预备样例减少现场输入，实际时长经彩排后调整；不承诺五分钟内展示所有功能。网页为主展示入口，APP不作为此次独立课堂演示的必选依赖。

## 最小验收标准

- 展示电脑不连接开发者电脑，能够按说明启动并打开本机网页；依赖准备完成后断网仍能加载界面并完成核心业务。
- 独立演示账号可以登录；学生组卷、作答、保存恢复、提交结果可用；家长固定预览发送及结果查看可用；错题重练可用。
- 正常停止再启动服务后，已保存的演示记录仍存在；不要求本批增加故障注入或大规模性能专项。
- 实际走完约五分钟彩排，记录所用版本、环境、结果及限制；未验证功能不写成通过。
- 源码、运行包、配置模板和演示说明指向同一课堂候选版本，秘密和真实个人数据不进入交接公开内容。
