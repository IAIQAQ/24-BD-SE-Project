## 1. 学生：先体验互动，再走完整练习

使用一年级`student_b`（当前昵称小明）登录。二、三年级也可分别使用`student_g2`、`student_g3`，各年级题库与原业务保持。

1. 首页看小芽叶片短暂摆动，点击“开始练习”。选本年级内容，把总题数改为5，再开始。
2. 填1题，看“幼苗”；填到3题，看“舒展”；5题全部填写后，看“长成”。清空一题应回到舒展。这里只表示已填写数量，不提前判对错。
3. 手动保存，再保存退出；从首页继续，答案与成长阶段应保留。如出现原有编辑锁提示，选择“在这里继续答题”。
4. 想听声音时，在“我的”或答题页主动开启“提示音”。声音默认关，可以随时关闭；网页和APP分别记住开关。
5. 填完并确认交卷，看真实成绩、短暂的小芽庆祝和逐题结果。回首页重看同一成绩，应保持静态，不重复庆祝。
6. 进入错题，选择错题再练；这是新的练习，原成绩保留。也可直接开始首页最新的“家长安排”5题任务。

## 2. 家长：安排与查看

退出学生登录，使用`parent_demo`。

1. 选择“一年级的小明”，避免与三年级同名孩子混淆。
2. 在练习任务中配置5题，预览后确认发送。学生登录后应能看到“家长安排”待完成任务。
3. 查看学生已完成的练习结果、原有学情和错题信息；本轮检查留下了一份80%（4/5）的五题成绩，也可查看自己刚完成的结果。

家长功能沿用现有范围，P3没有新增长期养成或S02完整学情统计。
