# S01 普通多知识点组卷

日期：2026-10-29。沿用 `/api/v1`、Cookie/CSRF、字符串ID及原作答接口。无新增schema迁移；V1—V7保留。

## 创建与家长预览

- 学生本人：`POST /practices`。
- 当前有效关联家长：`POST /family/children/{child}/previews`。

两者支持同一输入：

```json
{
  "allocations": [
    {"pointId": "1", "total": 2},
    {"pointId": "2", "total": 3}
  ],
  "operationKey": "一次操作的唯一编号"
}
```

知识点不得重复，分配1—100项，每项为1—100整数，合计1—100题。普通练习只选学生当前年级的启用分类及当前已审核启用题；不依赖历史错题来源。不足时返回409 `INSUFFICIENT_QUESTIONS`，列出不足项的名称、所需及可用数，整份不落库；不自动跨知识点补题。

旧 `{pointId,total,operationKey}` 单点请求继续兼容，省略total仍为30。单点表示与allocations同时提供时拒绝。旧单点哈希规则保留；一项allocations与对应旧单点请求使用同一键时可核对同一任务。多点按数值pointId排序后计算请求哈希，列表顺序变化不产生另一份卷；同键不同配置返回409 `KEY_REUSED`。

服务端逐项保存知识点、年级、名称和版本快照，逐题保存内容及知识点归属；类型为 `NORMAL`，来源仍独立为 `SELF` 或 `PARENT`。草稿不返回标准答案或解析；后续保存/接管/计时/提交/结果共用原流程。

## 配置与重试

共享配置表单初始为首个当前年级知识点、总量30。选择集合或总量变化时均分，余数按选择显示顺序分配；每项可手改，合计必须等于总量。点数多于总量时提示调整，不自动增加总量。

同一次配置的创建结果不明时保留operationKey；离开再打开配置仍保留题量与键。真正改变配置或接收人后才换键；重新输入同一个数值不换键。成功进入新练习后结束本次创建操作，下次可以按相同配置另建练习。

家长切孩子或修改配置会清除旧预览；异步预览返回时同时检查孩子与操作键。目录刷新后已选分类若消失，显示取消不可用知识点入口，不以隐藏选择卡住配置。

## 家长发送

复用 `POST /family/previews/{id}/send`，输入 `{confirm:true}`。预览15分钟有效，发送时复查当前ACTIVE关联、预览接收年级、全部分类名称/版本/启用状态和各题版本/审核/启用状态。发送不重抽题，题干和顺序固定；重复发送返回同一任务。撤回与开始沿用原状态控制。

统计继续按题目知识点快照归属。例如A2+B3，A对1、B对2，汇总3/5＝60.00%，不能按一卷总量向两个知识点各记5题。
