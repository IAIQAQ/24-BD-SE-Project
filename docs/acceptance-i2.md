## 使用

本机启动数据库、HTTPS后端和Vite后打开http://localhost:5173；Android安装delivery/mathdrill-i2-debug.apk并通过adb reverse转发18443。测试脚本 `./scripts/test-i1-device.ps1 -Serial emulator-5554 -Version i2 -Install -IncludeRoles`。完整I2测试依赖演示家长parent_demo已关联student_a；此关系通过真实注册/确认建立，不由正式种子自动授予。

管理员在Web和APP使用同一角色界面，较多题目维护适合浏览器。公众注册只提供学生/家长。新增题和导入题必须核对后启用，演示分类不代表教材覆盖。

## 未验收与限制

- 新版尚未在Android16实体手机测试；模拟器不能证明实体输入、厂商后台限制或全部返回/强杀情形。
- Android已集成原生模板缓存与分享插件，系统文件选择/分享至其他应用未逐项实测；Web模板下载、文件选择、上传导入已实测。
- 家长记录目前显示最近100条，错题为只读事件列表；更多历史分页、错题强化练习、教师/班级未在本轮加入。
- 完成记录数学错误的“不重算、只标记”已通过后端回归；未单独进行该错误场景的全页面操作验收。
- 原120题为自编综合加法，算术脚本核对不等于教材逐页/教师内容审核；管理员测试通过不代表题库已通过教学审核。
- 未做全面弱网乱序、全部锁组合压力、独立秒表精度、长时间使用、真实儿童/家长试用与备份导入恢复演练。
- 私有SQL已导出，仍未验证新库还原。便携数据库位于专用临时目录，正式交付前应迁移到稳定位置。无公网部署、正式签名及正式隐私运营配置。

测试只在本项目执行，没有自动推送、发布或修改原个人报告。自动审批曾拒绝读取整个ChatGPT窗口的截图，原因是可能包含无关私人对话；后续通过项目浏览器标签及本应用模拟器证据完成验证，没有再次读取该窗口。
