# I1 内容核对记录

2026-10-28。范围：一年级20以内加法综合复习，120道自编口算题，用于内部技术验证。

范围依据为教育部《义务教育数学课程标准（2022年版）》第一学段及入学适应期的20以内数加减法要求：[官方课程标准](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582346895190.pdf)。这是综合范围映射；尚无特定教材逐页证据，未称为某版教材原题，也未完成教师逐题审核。

数据 `data/catalog-120.json`：两个加数a、b为非负整数，a≤b、a+b≤20，排除交换加数的重复，只排除0+20，合计120题。保留0+0作为零答案边界，最大结果20。

核对脚本采用计数序列长度独立检查生成器的加法结果，逐条校验题干、解析、范围和去重。2026-10-28运行 `node scripts/verify-catalog.mjs` 通过；这证明数据满足算术与模板规则，不代表教师内容审核。

解析统一解释“从a开始，再增加b，得到和”，不复制教材文本。人工可直接检查0+0=0、0+8=8、8+7在归一顺序下为7+8=15、9+9=18、10+10=20等边界。固定验收文件 `backend/src/test/resources/acceptance-30.json` 给出30道固定源题与24对/4错/2漏预期；正常产品仍随机组卷，答案仅保留后端。

数据库 reviewed=true 在本内部版本中仅表示规则核对通过，不表示具备面向儿童公开试用的内容审核资格。公开试用前应补教材映射与人工审核；现已执行的V3迁移不重写，后续内容调整新增迁移。
