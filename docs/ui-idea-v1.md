日期：2026-10-30。状态：讨论结论与初版设计，尚未实施。

> 最新修订：P1已由用户体验通过；首版P2因整体视觉偏离B1被用户要求修正。后续P2以[视觉修订idea V2](ui-p2-visual-revision.md)为准，不能将本文件“两张小芽素材”的原范围作为完成B视觉的充分条件。

## 核心方向

**B的视觉方向，A的布局和交互先落地。** 保留清爽绿色，让低年级学生少读说明、通过卡片和图标找到操作；基础版可以独立交付，再加入静态小芽和少量鼓励。动效最后单独决定。

用户已体验学生、家长主要业务，认为总体流程与逻辑没有问题。本次解决文字过多、重点不突出、图形化不足，不重新设计登录、组卷、保存恢复、判分或家庭权限。

## 三个阶段

| 阶段 | 内容 | 交付定位 |
|---|---|---|
| P1 基础版 | 文案精简、大卡片、统一图标、题量快捷选择、清楚的答题与错题操作，家长端摘要化 | 完整可交付版本，必须先通过用户体验 |
| P2 小芽版 | 首页、完成页、空状态加入静态小芽及短鼓励语 | 在P1上增量完成，插画缺失也不影响业务 |
| P3 可选动效 | 小芽轻微摆动、完成时短暂庆祝 | 默认不执行；需要用户另行选定 |

P1预计12—20个有效工作小时，P2追加4—8小时，P3另加3—6小时。是工程初估，不是日历承诺；用户反馈导致的布局调整另记录。P1形成独立产物后再开始P2，时间不足即保留P1交付。

## 页面方案

- 登录：保留账号、密码、登录；辅助操作降低视觉权重，提示短而明确。
- 学生首页：主按钮“开始练习”；练习记录采用大卡片，明确“家长安排/继续/查看结果”。不新增学生完整学情或统计仪表盘。
- 配置：知识点大卡片，选中有勾选及边框；5/10/20题快捷按钮和自定义入口。保留原默认30题、1—100题范围、多点逐项分配及全部校验。
- 答题：算式、输入框、上一题/下一题优先；“已保存”小状态，题号面板折叠。错误、未保存、接管等需要用户决定的状态不能被装饰遮住。
- 结果：突出“答对X/共Y题”和正确率，可用普通进度条；逐题答案、解析按需展开，用时及提交信息为次要信息。不把错题自动标记已掌握。
- 错题：大算式卡片，明确选择状态；“再做一次”“练同类题”对应现有原题重练/同类强化，历史和规则折叠展示。跨页选择、不同历史年级分组继续保留。
- 家长：孩子选择醒目，任务、结果、学情用摘要卡片；详细知识点/日期统计可展开，日期筛选仍可用。预览接收人、题目、确认发送、撤回、只读权限及最近100条范围保持。
- 家庭、我的、注册：统一间距、图标及短文案，不减少关联确认、年级修改说明或必要输入项。
- 管理员：保留原业务与页面组织；共享样式变化后做必要回归检查，不纳入儿童视觉重做范围。

## 图形与文字规则

- 保留森林绿#285b49、米白#f4f7ef、浅绿#e8f0dd；P2少量加入暖黄/浅桃色。
- 正文目标16px以上，次要信息不小于14px，算式32—40px，主要点击区至少48×48 CSS像素；这些是本项目设计目标，需用真实页面检查。
- 图标配短标签，不仅靠颜色区别选中、错误或任务状态。错误不使用羞辱性表情或评价。
- 核心页面每块说明尽量1句，规则收进“说明”展开区域；交卷后不能改答案、漏答计分、未保存替换、接收人确认等关键事实必须在决策前可见。
- 所有进度取真实可用数据。首页Summary未必提供已答数，不把currentSeq当作已答数或编造“2/5已完成”；可显示“继续练习”，必要时显示“上次看到第N题”。
- P2角色为双叶小芽、圆脸、简单花盆；只做欢迎/完成两套静态素材，空状态复用欢迎素材。素材不包含按钮、题目或正文，文字仍由网页渲染。
- 不增加积分、连续签到、勋章、长期养成、语音、音效或新的数据库状态。小芽反馈由现有页面状态驱动。
