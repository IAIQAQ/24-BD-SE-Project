# 小芽口算最终演示流程

版本：S01。软件开发已完成，S02学生完整学情已取消。建议以测试库演示；启动步骤见 [最终启动说明](startup-final.md)。本文件是操作脚本，实际演示或录制后才记作新的演示证据。

## 演示前

- 数据库、S01后端和Web或APP能正常访问；不在现场重建环境或重跑整套测试。
- 备好隔离学生/家长及管理员登录资料，不把密码展示在投屏、文档或视频中。
- 确认当前学生和孩子，使用S01隔离A/B知识点；不修改原开发库题库或删除历史记录。
- 已有51项后端、29项前端和5条Android14流程结果可作为工程证据；现场演示不需要重复每一项。

## 主线一：学生自主练习（约2分钟）

1. 学生登录，点“开始新练习”。取消默认综合加法，选择S01验收A/B，设总量5、A2题+B3题。
2. 生成练习，说明每份题目不重复，逐项题量准确。
3. 填首题，点“手动保存”，再“保存退出”。从记录继续；若提示已在其他地方打开，明确选择“在此继续”。核对题目和已保存答案。
4. 完成5题，故意留1道错答或漏答，点“结束并检查”；如有漏答，展示返回补答或明确确认漏答的选择。
5. 提交后展示正确率、逐题答案及解析。按当次实际输入解释结果，不预先承诺某个随机卷的分数。

## 主线二：家长安排与查看（约2分钟）

1. 切到家长账号，确认当前孩子，进入“练习任务”。
2. 同样配置A2+B3，生成实际题目预览。先取消一次发送确认，说明取消不发送；再核对接收对象并发送。
3. 学生账号打开带“家长安排”的待完成任务，核对与预览相同的题目/顺序，完成并提交。
4. 家长查看该任务结果和孩子学情，说明家长只读、不能代答。

## 主线三：错题巩固（约1—2分钟）

1. 学生打开刚才的错题，查看历次作答。
2. 选择“原题重练”，展示新卷空白开始、使用原历史题干；完成后原错误和原成绩仍保留。
3. 时间允许再展示“同类强化”配置入口，说明按历史知识点从当前可用题池抽题。样例池不足时展示真实不足提示，不把强化描述为保证新题。

## 管理员补充（约1分钟，可按展示时长取舍）

管理员登录，展示分类、题库审核启停及Excel模板/预校验入口。使用既有隔离样例查看即可；不在现场标记演示中正在使用的题为数学错误，也不为了展示随意批量导入。

## 结束时的准确表述

- 已完成学生、家长、管理员主要流程，以及普通多点组卷、重练和强化；APP/Web共用前端与统一后端。
- 当前题库以自编加法为主，标准答案为非负整数；学生完整学情不在最终开发范围，家长学情已有。
- 当前是本机运行版本，公网入口待服务器确定后部署。未单独完成的真机、压力、弱网等专项验证如实列为未测，不用现场演示替代。
