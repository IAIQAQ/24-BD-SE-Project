# 儿童界面分阶段改版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 先提供可独立交付的少文字、大卡片版本，再增量加入静态小芽。

> 后续P2执行改用[示意图视觉对齐计划](2026-10-30-p2-visual-alignment.md)。ui-p2-v1已完成原技术范围，但用户指出整体视觉未达到B1；它是保留的可运行版本，不是已通过视觉验收的B方案。

**Architecture:** 沿用现有Vue视图和composables，改展示层及少量界面状态。图标与小芽独立呈现，接口和数据流保持。每个交付点保留独立产物和用户体验反馈。

**Tech Stack:** Vue 3、TypeScript、现有CSS、Vitest、Capacitor；不新增UI框架或图标依赖。

**Spec:** [儿童界面初版idea V1](../../ui-idea-v1.md)

> 2026-10-30执行状态：用户授权的P1实现、前端32项检查、类型/Web/Android构建及网页核心体验检查已完成，交用户体验；最终独立产物为ui-p1-v2（v1作为中间包保留）。P2/P3未开始。详细实际覆盖和未测项见dev-window-progress最新记录；下文保留原计划，不将未执行的专项或用户验收勾作完成。

## Global Constraints

- B的视觉方向，A的布局和交互先落地；P1先交用户体验，P2以后开始，P3默认不执行。
- 不重构业务状态机，不改API/schema，不删除任何功能、历史数据或验收数据；S02仍取消。
- 保留默认30题、1—100题及多点分配、错题跨页选择/历史年级分组、接管确认和不确定提交核对。
- 图标配短标签；主要点击区至少48×48 CSS像素；正文目标16px以上、次要信息不小于14px。
- 不虚构进度；不增加积分、签到、勋章、长期养成、声音或数据库状态。
- 不做自动模拟器验收；不自动暂存、提交、推送、配置远端或上传。技能通用流程中的提交/分支操作不覆盖用户限制。
- 当前HEAD 814cfbaa13b8ab58283579c2b6fb85cc6221bbcf之后有多批未提交源码和题库；先核对完整工作区，不只从HEAD开新工作树，不reset/clean。

## Review Focus

1. 三个年级及空目录/长知识点名称：不溢出、不选到其他年级内容；由T2检查。
2. 多知识点总量、同值重复点击及不确定重试：保持原分配和operationKey语义；由T2测试。
3. 未保存、编辑冲突和提交结果不确定：关键说明和动作仍可见，折叠不丢输入；由T3检查。
4. 家长切换孩子、迟到响应及预览：接收人、题目和确认始终一致；由T4测试。
5. 键盘焦点、窄屏、长算式及减少动态效果设置：操作可达，插画不遮挡；由T1/T3/T6检查。
