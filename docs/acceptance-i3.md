## 复现与产物

复用现有环境：依次运行 `scripts/start-database.ps1`、`scripts/start-backend.ps1`；Web在frontend运行 `npm run dev`。Android通过 `adb reverse tcp:18443 tcp:18443` 访问本机后端。

全量回归：`scripts/test-backend.ps1`；frontend运行 `npm run test -- --run` 和 `npm run build`。Windows受限临时目录出现EPERM时使用项目内 `.local/test-tmp` 作为TEMP/TMP；不能把环境启动失败计为业务测试失败或通过。

Android：`scripts/build-android.ps1 -Version i3`，然后 `scripts/test-i1-device.ps1 -Serial emulator-5554 -Version i3 -Install -IncludeRoles -IncludeLearning`。完整角色UI回归依赖本机已有的有效演示家庭关联与演示账号；密码从.local私有配置临时传入，脚本finally清除。本轮已确认本地及模拟器上无遗留i1-probe.json。

交付文件为 `delivery/mathdrill-i3-debug.apk`、`mathdrill-i3-test.apk`、`mathdrill-i3-backend.jar`、`mathdrill-i3-web.zip`；校验信息 `delivery/manifest-i3.json`。私有源码/数据库备份及扫描记录见同清单，含数据的备份不公开。
