## 正常体验流程

1. 使用对应年级学生登录→开始新练习→选择本年级一项或多项内容→总题数填5→开始。默认总题数仍是30，可以自行调整。
2. 做一两题→手动保存→保存退出→从列表继续；如提示练习已在别处打开，明确选择在这里继续。完成交卷→查看逐题结果→错题再练。
3. 家长登录→选想体验的孩子→练习任务→同样配置5题→预览并发送；对应学生收到任务后完成，家长查看结果及学情。
4. 管理员查看正常分类和390道题，不为体验删除或停用正在使用的题目。

本轮按已批准方案补至390道基础整数运算题，11个知识点：

| 年级 | 内容与题数 |
|---|---|
| 一年级 | 10以内加法36题、得数11至20的加法84题、20以内减法30题；共150题 |
| 二年级 | 100以内加法、减法、表内乘法、表内除法，各30题；共120题 |
| 三年级 | 整十整百数加法、减法（1000以内），简单两位数乘一位数、两三位数除以一位数（整除），各30题；共120题 |

答案继续限定非负整数，除法仅整除且除数非零。每份练习抽到不同题目，跨次练习可能重复。该范围是基础口算体验样例，不代表完整教材或所有题型覆盖。
